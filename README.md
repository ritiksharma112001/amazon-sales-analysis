# Amazon Sales Analysis | SQL, Python & Power BI

## Project Overview
This project analyzes Amazon sales data to identify sales trends, customer order patterns, product category performance, regional performance, and order fulfilment issues.

## Tools & Technologies
- **PostgreSQL:** Business analysis using SQL queries
- **Python:** Data cleaning and preprocessing
- **Pandas:** Data manipulation
- **Jupyter Notebook:** Data cleaning workflow
- **Power BI:** Interactive dashboard and visualization

## Project Workflow
1. Cleaned and prepared the sales dataset using Python and Pandas.
2. Analyzed the data using PostgreSQL and business-driven SQL questions.
3. Built a Power BI dashboard to visualize key sales and order metrics.
4. Documented the analysis and findings in the project report.

## Key Business Insights
- The Set category generated the highest sales and revenue.
- Maharashtra recorded the highest number of delivered orders.
- Maharashtra also recorded the highest number of cancelled orders.
- The cancellation rate was 12.86% for Amazon fulfilment and 17.54% for Merchant fulfilment.

## Project Files
- `amazon_sales_analysis.sql` — SQL analysis queries
- `amazon_sales_data_cleaning.ipynb` — Python data cleaning notebook
- Project PDF — Detailed analysis, results, and visualizations

## Dataset
The project uses Amazon sales data sourced from Kaggle.
